# AskThis 新手教程

> 不用编程：装好应用，接入模型，按一个快捷键就能问。

## 1. 这是什么？

AskThis 把 AI 放进一张随时可打开的小卡片。默认快捷键是 **Mac `⌥⇧D`（Option + Shift + D）/ Windows、Linux `Alt+Shift+D`**。

- **有文字要查**：选中术语、段落或代码 → 按快捷键 → 看解释或翻译。
- **有问题想问**：不选文字 → 按快捷键 → 直接打字 → 按 `Enter` 发送。
- **有内容要粘贴**：不选文字 → 按快捷键 → 手动粘贴 → 按 `Enter` 发送。

v0.1.4 默认自动模式在没有选区时打开空白输入框，**不会自动提交你之前复制的内容**。输入框会自动聚焦，不必再点一下。按 `Esc` 可关闭卡片。

AskThis 本身免费开源，不提供内置云端模型额度。你需要自己的 API 密钥，或已运行的本地模型服务。**网页聊天会员不一定包含 API 额度**，请到服务商的 API 平台确认。

## 2. 下载安装

打开 **[最新版本下载页](https://github.com/537Lab/askthis/releases/latest)**，展开 **Assets**。下面的文件名以 `<版本号>` 代指页面上的版本，**不用下载 Source code**。

### Mac

1. 在「苹果菜单 → 关于本机」查看芯片：
   - 显示 **Apple M 系列**：选 `AskThis-<版本号>-arm64.dmg`。
   - 显示 **Intel**：选 `AskThis-<版本号>-x64.dmg`。
2. 打开 `.dmg`，把 **AskThis 拖进「应用程序」**。
3. 从「应用程序」打开 AskThis。手动启动会打开设置；平时它常驻菜单栏。
4. 若被系统拦截：先确认安装包来自上面的仓库。可尝试右键点应用 →「打开」，或按「系统设置 → 隐私与安全性」中的「仍要打开」提示操作。具体提示因 macOS 版本而异。

发行版没有 Apple Developer ID 签名与公证。不要为安装它关闭整个系统的安全保护。若你已核实来源、但仍遇到隔离属性拦截，可对该应用单独执行：

```bash
xattr -dr com.apple.quarantine /Applications/AskThis.app
```

此命令只移除指定 AskThis 应用的下载隔离标记，不是必须执行的常规步骤。

### Windows

1. 一般 Intel / AMD 电脑选 `AskThis-<版本号>-setup-x64.exe`；Windows ARM 设备应选择对应的 `arm64` 安装包（若该版本提供）。
2. 双击安装。若出现「Windows 已保护你的电脑」，确认下载来源后选择「更多信息 → 仍要运行」。
3. 不想安装，可选名称含 `portable` 的便携版。启动后在任务栏右下角托盘找 AskThis。

### Linux

下载对应 `.AppImage` 或 `.deb`。Linux 构建尚未真机验证；X11 的选区捕获依赖 `xdotool`，Wayland 下建议手动输入 / 粘贴。全局快捷键支持取决于桌面环境。

> **平台状态**：macOS 是当前主要验证平台。Windows 旧版已验证安装、启动和快捷键，但 **v0.1.4 新交互仍待 Windows 真机复验**；Linux 尚未真机验证。安装包存在不等于所有功能在每个平台都经过验证。

## 3. 接入 AI 服务

API 密钥像一把让 AskThis 调用模型的钥匙。它不等于网站登录密码，也不要发给其他人。

以 DeepSeek 为例（也可以换成你已有的其他服务）：

1. 打开 <https://platform.deepseek.com>，注册或登录。
2. 在平台的 API keys / 密钥管理页面创建密钥，并妥善保存。若平台要求充值，请先查看当前价格、额度与付款规则。
3. 回到 AskThis → **设置 → 模型服务**，选择已有的 DeepSeek 条目；没有则点「添加服务」。
4. 把密钥填进 **API 密钥** 栏并保存。
5. 点 **获取模型列表**，选择账号实际可用的模型；确认「当前使用」里的服务与模型正确。
6. 可先用「测试连接」检查配置，再试一次简短提问。

## 4. 第一次提问：先直接输入

1. 取消当前应用里的文字选区（例如点一下普通空白处）。
2. 按 **`⌥⇧D` / `Alt+Shift+D`**。
3. 出现空白卡片后，直接输入：**「用一句话解释什么是递归」**。
4. 按 **`Enter`** 发送，等待流式回答；可在下方继续追问。
5. 按 **`Esc`** 关闭卡片。使用中文输入法时，选词确认不会当作发送；选词期间的 `Esc` 优先处理输入法。

![无选区输入卡片：输入框已准备好接收问题](images/manual-input.png)

**试一试剪贴板保护**：先复制一段无关文字，再取消选区并按快捷键。默认自动模式应显示空白输入框，而不是查询那段旧文字。确实想问复制来的内容时，自己粘贴，再按 `Enter`。

### 再试「选中即问」

1. 在网页或文档中选中一个术语或一小段话。
2. 按同一个快捷键；读取成功后会自动查询，不用再按发送。
3. Mac 若提示「辅助功能」权限：按提示到「系统设置 → 隐私与安全性 → 辅助功能」添加并开启 AskThis，然后重启应用、重新选择文字再试。
4. 若目标应用不支持读取选区，先自己复制，再打开卡片粘贴提问。

## 5. 日常操作与三种获取方式

| 想做什么 | 怎么做 |
| --- | --- |
| 查一个词 / 一段话 | 选中 → 快捷键（默认自动模式） |
| 直接问问题 | 无选区 → 快捷键 → 输入 → `Enter` |
| 查询复制来的文字 | 打开空白卡片 → 粘贴 → `Enter` |
| 继续追问 | 在卡片底部输入 → `Enter` |
| 复制答案 | 点「复制结果」，卡片随后关闭 |
| 关闭卡片 | `Esc`、右上 ✕ 或「关闭」 |
| 换服务 / 模型 | 设置 → 模型服务 |
| 换快捷键 | 设置 → 快捷键与交互 |
| 换语言 / 主题 | 设置 → 通用 |

**设置 → 通用 → 内容获取方式**：

- **自动（优先选中文本）**：默认选项。有选区就查询，没读到就等你输入；不自动查询旧剪贴板。
- **手动输入**：无论其他应用有没有选区，都打开输入卡片；适合随手提问，也能避开选区捕获时的模拟复制。
- **仅使用剪贴板**：你明确选择后，快捷键会读取并查询剪贴板文字。注意不要把敏感内容留在剪贴板后误触发。

## 6. 常见问题

### 无选区时为什么不再查询剪贴板？

这是 v0.1.4 的行为调整：不让旧的复制内容意外变成问题。默认自动模式下直接输入或手动粘贴即可；仍想保留剪贴板工作流，请显式选择「仅使用剪贴板」。

### 快捷键没反应？

- 先确认 AskThis 正在运行：Mac 看菜单栏，Windows 看托盘。
- 可能被其他软件占用，到「设置 → 快捷键与交互」换组合；注册失败时会显示警告。
- Linux 尤其是 Wayland，快捷键受桌面环境限制，请反馈系统和会话类型。

### Mac 更新后读不到选中文字？

更新会改变应用签名，系统可能要求重新授权。到「系统设置 → 隐私与安全性 → 辅助功能」检查 AskThis；若开关无效，移除旧条目，重新添加「应用程序」里的 AskThis 并开启，重启后再试。钥匙串弹窗需由你确认访问权限。不要把密码或 API 密钥贴到 Issue 中。

### 提示「请求失败 / 超时 / 未配置密钥」？

检查「当前使用」的服务和模型、密钥是否保存、账号余额 / 模型权限，以及网络。使用代理时启用代理软件的「系统代理」模式。服务商网页聊天能用，并不代表 API 已开通。

### 会花多少钱？

AskThis 不收费，云端 API 按服务商规则计费，价格与用量有关。先做一次简短查询并在服务商后台查看用量；可调低「最大输出长度」控制回答长度。本地模型通常不收云端 API 费，但占用本机资源。

### 文字发到哪里？会自动发剪贴板吗？

请求直接发到你配置的模型服务，不经过 AskThis 中转。选中文字会自动查询；手动输入 / 粘贴要按 `Enter`；默认自动模式不会发送旧剪贴板，但显式剪贴板模式会。历史记录在本机，可在通用设置中关闭保存或清空。

### 能截图识字、读图片或扫描 PDF 吗？

不能。当前没有 OCR / 截图识字；需要先用其他工具提取文字，再粘贴提问。

### 在终端里用会影响正在运行的命令吗？

选区捕获可能模拟复制，Windows / Linux 的 `Ctrl+C` 可能中断终端进程。终端场景建议先在「内容获取方式」中选「手动输入」，再用卡片输入或粘贴。复制回退也不能保证完整恢复图片等非文本剪贴板内容。
